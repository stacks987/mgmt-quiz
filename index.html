Couldn't find data.js. Make sure index.html and data.js are in the same folder, and that you're opening this over http:// (a local server) rather than double-clicking the file directly — some browsers block local scripts from loading each other over a plain file:// path. A one-line fix: open a terminal in this folder and run python3 -m http.server 8000, then visit http://localhost:8000.
